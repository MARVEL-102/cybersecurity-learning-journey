1. Linux Administration and System Security

Through my SecureBank Linux administration assignment, I developed an understanding of Linux operating systems and their importance in cybersecurity.

Some of the areas I practised include:

* Navigating the Linux filesystem using terminal commands.
* Identifying hidden files and directories.
* Creating, managing and organizing files.
* Understanding file permissions and access control.
* Monitoring running processes.
* Checking network connections and listening ports.
* Reading system logs and identifying suspicious activities.
* Understanding system updates and basic security practices.

My understanding: Linux is an important operating system in cybersecurity because it provides powerful tools for system administration, monitoring, troubleshooting and security investigation.

2. Network Reconnaissance and Scanning with Nmap

Through TryHackMe practical exercises, I gained an understanding of Nmap and how it helps cybersecurity professionals discover information about target systems.

Some of the techniques I studied and practised include:

* TCP Connect Scanning.
* SYN Scanning.
* UDP Scanning.
* NULL, FIN and Xmas Scanning.
* Service and Version Detection.
* Operating System Detection.
* Network and Host Discovery.
* ICMP Ping Sweeps.
* Nmap Scripting Engine (NSE).
* Port scanning and enumeration.
* Scan timing, verbosity and output formats.

My understanding: Nmap is a powerful network reconnaissance tool that helps security analysts identify active hosts, discover open and closed ports, detect running services and gather information about target systems.

Understanding scan results helps analysts identify possible security weaknesses and determine areas that require further investigation.

3. Web Application Security Testing

I have also been introduced to web application security testing using:

* Burp Suite Community Edition.
* OWASP ZAP.

Through practical learning, I developed an understanding of how proxy tools work between a browser and a web application.

Some of the concepts I explored include:

* Intercepting HTTP requests and responses.
* Understanding how web applications communicate.
* Observing login requests and authentication parameters.
* Understanding multi-factor authentication (MFA).
* Exploring authentication logic vulnerabilities in authorised PortSwigger training labs.

My understanding: Web application security testing helps identify weaknesses in how applications handle user requests, authentication and access control.

These tools allow security learners and professionals to inspect application traffic and investigate potential vulnerabilities in authorised testing environments.
